gallery page — what goes where

Every photo and every piece of text on the page, in the order they appear. Each row shows the setting name to change in config.toml.

To swap a photo: put the new file in images/ and set the filename in config.toml. Then run ./build.py.

This file is generated — editing it does nothing.
